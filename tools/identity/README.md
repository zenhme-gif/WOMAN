# حزمة الهوية

- `colors.py`: قيم الألوان (الرسمية والمشتقة والمحايدة والدلالية، وألوان سلسلة «فقه المرأة المسلمة» المقيسة)، ومولّد ملفات ASE وJSON.
- `extract_series.py`: عناصر السلسلة من صفحة الغلاف الأصلية بخلفية شفافة (شعار السلسلة، النقاط الثلاث، اسم الشيخ، شريط الزخرفة).
- `build_guide.py` و`guide.css`: دليل الهوية (HTML)، و`print_pdf.js` يخرجه PDF بمقاس A4 ويقيس امتلاء كل صفحة ونسبة الشعار.
- `render_svg.js`: يرسم ملفات الشعار SVG إلى PNG شفاف بعرض محدد.

الناتج في `identity/`: الدليل PDF، والحزمة المضغوطة (الشعار SVG/PNG، الألوان ASE/CSS/JSON، خط تجوّل، عناصر السلسلة).
